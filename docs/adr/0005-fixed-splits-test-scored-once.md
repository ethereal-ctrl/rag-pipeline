# Fixed, stratified splits; the Test Split is scored once per variant

The 2,556 Benchmark Queries are split once, stratified by query type and with a fixed seed, into a Dev Split (~500, containing a ~50-query Smoke Set), a Test Split (~1,000) and an untouched reserve (the rest). All tuning happens on the Dev Split; each Pipeline Variant is scored on the Test Split once, for the published table, with bootstrap 95% confidence intervals so readers can see which gains are real (±~3 points at this size). This keeps the reported gains honest at the cost of not being able to "fix" a variant after seeing its test score. The Test Split is 1,000 rather than ~2,000 because local inference on an M4 makes each full run take hours; because of free-tier rate limits, the large remote model is scored only on a fixed ~400-query subset of it.
